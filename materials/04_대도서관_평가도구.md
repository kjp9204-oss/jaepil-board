# [대도서관 원고] 평가도구 안내 — 에이온 평가도구 페이지 이관

C.C 작성 · 2026-11-18 · 대도서관 새 메뉴(또는 자료 유형) 「평가도구」용

- 원문(에이온): `research-library.html`(평가도구 검색 페이지), `assets/outcome-measures.js`(도구 14개 자료), `resources.html`(옛 자료실 안내 → 평가도구로 이동한 페이지)
- 대도서관에는 10-13에 에이온 **논문 색인**(`imports/aon-20261013/`)만 옮겨졌고, 평가도구 페이지는 그 뒤에 만들어져 아직 없습니다.
- 계산기·검색은 원문 스크립트(`outcome-measures.js`)를 그대로 쓰거나 대도서관 검색에 합치면 됩니다. 방식은 를르슈가 대도서관 구조에 맞춰 정합니다.
- **설문 문항 파일은 지금처럼 올리지 않습니다.** 원문과 같이 안내와 공식 출처만 둡니다.

## 1. 페이지 머리말

### 평가도구 — 변화를 살피는 하나의 기준

통증의 크기만으로는 알기 어려운 일상의 변화가 있습니다. 목적에 맞는 설문과 평가도구를 찾아보세요.

**점수보다 먼저, 무엇을 볼지 정합니다**

1. **목적에 맞게 고르기** — 어떤 증상과 생활의 변화를 확인할지 먼저 정합니다.
2. **판본과 사용 조건 확인** — 공식 원본, 한국어판, 이용 범위를 확인합니다.
3. **상담과 평가에 함께 쓰기** — 점수만으로 진단하거나 회복을 판단하지 않습니다.

## 3. 꼬리말 (주의 문구)

**같은 기준으로 기록하고, 사람의 맥락에서 해석합니다**

- 도구의 문항·순서·응답 선택지·채점 기준과 언어판은 임의로 바꾸지 않습니다. 이 사이트는 원도구의 개발자가 아니며, 각 도구의 저작권과 사용 조건을 따릅니다.
- 공식 출처에 양식이 공개되어 있어도 다른 사이트의 재게시나 전자 설문 제작까지 허용된 것은 아닐 수 있습니다. 확인된 범위 안에서만 파일을 제공합니다.
- 이 페이지는 도구 안내용입니다. 설문지나 개인 평가 결과를 제공하지 않습니다. 한국어 제목은 찾기 쉽게 붙인 안내명입니다.
- 점수는 단독 진단이 아닙니다. 적용 대상과 지침을 확인하고 상담·신체평가·목표와 함께 해석해야 합니다.
